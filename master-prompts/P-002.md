PROMPT MAESTRO P-002 — APP SHELL (POST-LOGIN) + NAVEGACIÓN INTERNA
USAR DESPUÉS DE prompt_landing_page. GENERA EL “ESQUELETO” DE LA APLICACIÓN PARA QUE TODAS LAS PÁGINAS CORE ENCAJEN. IDIOMA: ESPAÑOL. ESTILO CÁLIDO, COMMUNITY, LIMPIO. ENFOQUE: PRODUCTIVIDAD SUAVE (SIN RUIDO).

RUTA: /app (y estructura común para /app/*)

OBJETIVO:
Crear AppShell reusable con:
- Topbar con búsqueda global
- SideNav (desktop) + bottom nav o drawer (mobile)
- Área de contenido con Container
- Estados: usuario nuevo (sin datos), loading, error
- Notificaciones suaves (no intrusivas)

========================
1) APP SHELL — ESTRUCTURA
========================
COMPONENTES OBLIGATORIOS: AppShell, NavBar/Topbar, SideNav, Container, SearchBar, Button, Avatar, Badge.

TOPBAR (sticky)
- Fondo: crema semitransparente + blur suave
- Altura: 72px desktop / 64px mobile
- Izquierda: logo “Wordelia” (clic a /app/mi-lectura)
- Centro: SearchBar global con placeholder:
  “Busca libros, clubs, autores…”
  - icono lupa
  - atajo “/” (opcional) como hint discreto
- Derecha:
  - icono de notificaciones (Badge contador opcional)
  - avatar usuario (abre menú)
MENÚ AVATAR (dropdown):
- “Perfil”
- “Preferencias”
- “Privacidad”
- “Ayuda”
- “Cerrar sesión”

SIDENAV (desktop, izquierda)
- Ancho 260–280px, fondo crema, separadores sutiles
- Items (icono + texto):
  1) Mi lectura     -> /app/mi-lectura
  2) Explorar       -> /app/explorar
  3) Clubs          -> /app/clubs
  4) IA Literaria   -> /app/ia
  5) Guardados      -> /app/guardados (listas/shelves)
  6) Perfil         -> /app/perfil
- Item activo: fondo teal muy pálido + borde izquierdo teal
- Al final (footer del nav): enlace pequeño “Recursos” -> /recursos y “Normas” -> /normas

MOBILE NAV
- Opción A (recomendada): BottomNav con 4 items + “Más”
  - Mi lectura, Explorar, Clubs, Perfil, Más
  - “Más” abre drawer con IA Literaria, Guardados, Ajustes, Ayuda
- Opción B: hamburguesa + drawer lateral (si prefieres)
Mantener targets 44px.

CONTENT AREA
- Container max 1200px, padding 24px
- Breadcrumbs opcional en páginas profundas

========================
2) ESTADOS GLOBALES (DEBES INCLUIR)
========================
LOADING:
- Skeleton en topbar search results + skeleton cards en contenido

EMPTY (usuario nuevo):
- EmptyState centrado, cálido:
  - Título: “Tu rincón de lectura está listo”
  - Texto: “Añade tu primer libro o únete a un club para empezar con calma.”
  - Botones: “Explorar libros” (primary) + “Explorar clubs” (secondary)

ERROR:
- ErrorState:
  - “Algo no ha ido bien”
  - Botón: “Reintentar”
  - Link: “Centro de ayuda”

========================
3) NOTIFICACIONES (SUAVES)
========================

  - “Libro añadido”

- No usar popups agresivos.
